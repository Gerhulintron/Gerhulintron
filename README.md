# Hi, I'm Kyle Hinton 👋

### Full-Stack Developer · Game Developer · Creative Technologist

I'm a Calgary-based developer who builds full-stack web applications, games, augmented-reality experiences, interactive media, and creative technology.

I especially love integrating software with real-world systems. My work has included geospatial applications, AR scavenger hunts, synchronized audiovisual experiences, mobile and browser games, educational platforms, blockchain-powered creative tools, and production web applications.

I enjoy working across the entire development process—from architecture, databases, APIs, authentication, and deployment to interface design, gameplay systems, testing, debugging, and the strange technical problems that emerge when software meets people, devices, physical spaces, and live experiences.

## What I Build

* Full-stack applications using Django, Python, React, JavaScript, TypeScript, PostgreSQL, and REST APIs
* Unity games for mobile, WebGL, and desktop using C#
* Augmented-reality and geospatial experiences using AR Foundation, Mapbox, and location services
* Blockchain applications using Solana, wallet integrations, token-gated access, and digital assets
* Interactive media involving synchronized audio, video, animation, sound design, and physical performance
* Cloud-deployed applications using DigitalOcean, Firebase, Nginx, Gunicorn, GitHub Actions, and managed databases

## Selected Projects

### [MuultiSpace](https://muulti.xyz)

MuultiSpace is a web platform that allows people to create personalized and interactive web spaces connected to their digital wallets.

I have worked across its React frontend, Django REST backend, authentication systems, PostgreSQL database, media handling, Solana integrations, token-gated access systems, cloud deployment, and ongoing product development.

**Technologies:** React, JavaScript, TypeScript, Python, Django, Django REST Framework, PostgreSQL, Solana, Metaplex, DigitalOcean

[View the frontend repository](https://github.com/Gerhulintron/MuultiClient)

---

### [Disinformation Warriors](https://github.com/Gerhulintron/DisinformationWarriors)

A bilingual Python and Django web platform developed as an educational and interactive experience around disinformation.

My work included backend development, content management, multilingual functionality, frontend integration, server deployment, domain configuration, SSL certificates, and long-term application maintenance.

**Technologies:** Python, Django, JavaScript, HTML, CSS, Linux, Nginx, Gunicorn

---

### [Bunny Runner](https://github.com/Gerhulintron/BunnsRunner)

A cross-platform Unity arcade runner created for Android, iOS/TestFlight, and WebGL.

I developed gameplay state systems, mobile input, jumping and movement mechanics, UI transitions, audio mixing, persistent settings, procedural spawning, score and ranking systems, platform-specific fixes, and deployment workflows.

The public repository contains the deployed WebGL build. Some Unity source code and production assets are maintained privately because of project ownership and asset-licensing requirements.

**Technologies:** Unity, C#, WebGL, Android, iOS, Unity Input System, Cinemachine, AudioMixer, PHP, MySQL

---

### [Asteroid Scan One](https://github.com/Gerhulintron/AsteroidScanOne)

A Python application that retrieves near-Earth-object data from NASA's NeoWs API and transforms the day's passing asteroids into a visual experience using Python's Turtle graphics library.

The visualization represents the relative size, ordering, and distance of each asteroid from Earth.

**Technologies:** Python, REST APIs, JSON, NASA NeoWs, Turtle graphics

---

### [Chibi Gacha Gotchi](https://github.com/Gerhulintron/ChibiGachaGotchi_Web_Build)

A deployed Unity WebGL game build exploring collectible characters, interactive systems, and browser-based game delivery.

The public repository contains the playable WebGL deployment, while the full Unity project is maintained separately.

**Technologies:** Unity, C#, WebGL

## Game and Interactive Development

Game development is a major part of my work. I am interested not only in gameplay mechanics, but also in the connections between games, physical spaces, performance, sound, education, and experimental storytelling.

Some of my additional game and interactive projects include:

### God of Thunder

A Unity game originally designed around voice-controlled mechanics before being adapted into a more traditional input system. The project includes character state systems, environmental interactions, animation, Cinemachine camera work, timelines, and event-driven gameplay.

### Lilly in the Lab

A mobile augmented-reality scavenger-hunt application using Unity, AR Foundation, Mapbox, geospatial markers, location services, branded location content, and mobile photo capture.

### Children of the Bear

An interactive audiovisual map experience built around four synchronized audio tracks, a 992-cell navigable grid, and timeline-driven visual events.

### The Suitcase Theatre Arcade

A long-running creative project combining miniature theatre, puppetry, physical objects, games, sound design, electronics, and interactive media inside suitcases, computer cases, and other unconventional spaces.

More game, web, and creative-technology projects can be found on my [project portfolio](https://kylehintonprojects.com).
