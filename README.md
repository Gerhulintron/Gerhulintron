# Hi, I'm Kyle Hinton 👋

**Creative Media Production & Development · Full-Stack Software · Unity Games**

I'm a developer and multidisciplinary artist based in Calgary. I build web apps, games, and interactive experiences, and I'm especially interested in what happens when software meets physical spaces, live performance, and sound.

I work across the whole build: figuring out what a product needs to do, designing its APIs and data, building the interface, and getting it into people's hands. Through [The Simulacrum](https://thesimulacrum.xyz), I bring that same approach to creative production.

[Portfolio](https://kylehintonprojects.com) · [The Simulacrum](https://thesimulacrum.xyz) · [LinkedIn](https://www.linkedin.com/in/kyle-hinton-236ba0165/)

## Selected work

- **[MuultiSpace](https://muultispace.com)** is a modular page builder that lets creators decide how people access their work. I build the editor, publishing, and access features with React, Firebase, and Solana. [Frontend repository](https://github.com/Gerhulintron/MuultiClient)
- **[The Suspicious Microwave Tower Defense](https://www.linkedin.com/posts/kylehinton777_web3gaming-gamedevelopment-towerdefense-activity-7506574448234450944-jHGo)** is a Unity game about defending against waves with modified microwaves. It's available on the Solana Mobile dApp Store.
- **[Audio at Play](https://www.audioatplay.ca)** is a sound library and storefront for field recordings, sound effects, and sample packs. I build the web app, from browsing and previews to checkout and downloads.
- **[Disinformation Warriors](https://github.com/Gerhulintron/DisinformationWarriors)** is a bilingual media-literacy and animation platform I helped design and build with Django. My work covered course and registration flows, multilingual content, deployment, and maintenance.
- **[The Suitcase Theatre Arcade](https://suitcasetheatrearcade.com)** puts miniature theatre, puppetry, sound, and games inside suitcases and other found objects.

## More to explore

- **[Bunny Runner](https://github.com/Gerhulintron/BunnsRunner)**: a Unity arcade runner built with the Guides team for mobile and WebGL. The public repository contains the WebGL build.
- **[Asteroid Scan One](https://github.com/Gerhulintron/AsteroidScanOne)**: a Python visualization of near-Earth objects using NASA's NeoWs API.
- **Lilly in the Lab** and **Children of the Bear**: a location-based AR scavenger hunt and a map with four synchronized audio tracks. Both are in my [portfolio](https://kylehintonprojects.com).
